# Contributing

This repository represents XXXX approved digital profile.

## Branches

- Learning proposals: `learn/YYYY-MM-DD-short-topic`
- Corrections, forgetting, and restoration: `review/YYYY-MM-DD-short-topic`
- Direct commits to `main` are not permitted.

## Pull requests

Use the pull request template. Keep each pull request focused on one coherent observation or correction. Yannick is the final reviewer and merger.

## Content standards

- Prefer precise, limited wording over absolute claims.
- Include evidence for learning proposals.
- Do not commit raw private conversations unless explicitly approved.
- Never commit credentials, secrets, or sensitive inference.
- Keep Markdown portable and understandable without a specific AI vendor.
